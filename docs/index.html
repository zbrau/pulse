Desktop focus app for Windows

Focus and music in one quiet window.

Pulse keeps your task list, a pomodoro timer, lofi radio and YouTube Music with synced lyrics in a single place. No accounts, no tabs, no noise.

Download for Windows View source

Free and open source · MIT · Windows 10/11 x64

Everything you need to sit down and work

Built for long sessions: clear priorities, a timer that does not drift, and music that gets out of the way.

Tasks with real priorities

High, medium and low groups, tags, pomodoro estimates and drag to reorder. Quick add understands !alta, #tag and *3.

A pomodoro that keeps time

Focus and break cycles, configurable long breaks, daily stats and a streak. The timer stores an end timestamp, so it never drifts.

YouTube Music, simplified

Search songs, artists and albums, build a queue and seek for real. The audio is resolved locally by yt-dlp, not by an external server.

Synced lyrics

Line-by-line lyrics matched by artist, title and duration through lrclib, with a manual search when nothing is playing.

Visualizer and equalizer

A spectrum drawn from the real signal and a five-band equalizer with presets. Both share the same Web Audio graph, so what you see is what you hear.

Spotify import

Paste a public playlist link or upload an Exportify CSV. Pulse matches each song on YouTube Music and saves the list on your machine.

Offline downloads

Pick a quality and keep songs on disk. They play through the same equalizer, show up in a storage manager, and work without a network.

Always-visible mini mode

Shrink Pulse to a compact, always-on-top window with the timer, the active task and music controls while you work elsewhere.

Automatic updates

New versions are published on GitHub and signed. Pulse checks in the background and installs the update from Settings.

Made for airplanes, cafés and bad Wi-Fi

Downloads are real files on your disk, served locally to the player. Seeking, the equalizer and the visualizer keep working the same way.

Downloads you control

Choose a quality preset, download from the search results and manage everything in one place.

  • Quality presets. From the best available audio to a smaller 96 kbps cap.
  • No re-encoding. Without ffmpeg, Pulse picks the original track under the limit instead of transcoding.
  • Storage manager. See how much each song uses, total size, free disk space and delete on the spot.
  • Offline first. If a song is downloaded, the player never asks the network for it.

Small window, same session

Mini mode is not a second app: it resizes the same window and keeps everything running.

  • Always on top. The timer stays visible above your editor or browser.
  • Active task and music. See what you are working on and control playback without restoring the full window.
  • No state lost. Queue, lyrics, radio and stats stay exactly where they were.
  • One click back. Return to the normal layout and size when you are done.

Three steps, no setup

Pulse stores everything locally. There is no sign-up, no sync service and no telemetry.

Write down the work

Add tasks with a priority and an estimate. The list groups itself and remembers the active task between sessions.

Start a session

Press space or hit start. The timer survives losing focus, and each completed pomodoro adds a point to the active task.

Put something on

Search YouTube Music or pick a lofi station. The radio pauses when a song starts, so there is only ever one source of sound.

Try Pulse on Windows

Download the installer from GitHub Releases. The app is not code-signed yet, so SmartScreen may ask for confirmation the first time. Updates after that are signed and verified automatically.
