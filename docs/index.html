INGENIERÍA ROBUSTA

¿Cómo funciona la arquitectura técnica en Rust?

Pulse no utiliza APIs frágiles ni servidores intermedios de terceros. Todo corre localmente en tu propio equipo.

1. innertube.rs
Consulta metadatos, artistas, álbumes y búsqueda directa en el catálogo de YouTube Music.
2. ytdlp.rs
Resuelve el enlace de stream de audio mediante un sidecar nativo de yt-dlp con caché en memoria.
3. proxy.rs
Proxy HTTP local en 127.0.0.1 que atiende peticiones Range para saltar en la canción sin restricciones de CORS.
4. lyrics.rs
Parser y sincronizador de marcas de tiempo LRC con LRCLIB para pintar el karaoke al milisegundo.
